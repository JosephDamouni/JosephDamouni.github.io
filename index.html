Desk Gadget

A small personal dashboard for one user's own Google account.

Desk Gadget is a private tool written for and used by a single person, Joseph (Rani) Damouni. It is not offered to the public and has no other users.

It runs on the owner's own Windows laptop and iPhone and shows, in one small panel:

  • Google Tasks: open tasks, with the option to add a task or mark one done
  • Google Calendar: upcoming events (read-only)
  • Gmail: important messages, and course emails about homework (read-only)

How data is handled is described in the privacy policy.
